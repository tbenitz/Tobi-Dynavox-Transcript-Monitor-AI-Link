# AAC Link v0.1.0 preview

Download **AACLink.exe** for Windows x64. Run it, select the local UTF-8 transcript file, focus Notepad, then press **F9** to test insertion before trying your AAC app.

Includes the tray monitor, no-activate suggestion strip, hotkey and macro triggers, settings for placement and accidental presses, built-in offline predictions, optional local Qwen models through Ollama, and opt-in DeepSeek and Grok.

This unsigned portable preview has not been tested on a Tobii Dynavox device. Compatibility with individual AAC message bars can vary. The app never presses Enter or Speak.
