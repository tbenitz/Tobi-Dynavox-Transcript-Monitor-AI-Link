# AAC Link v0.1.1 preview

In **Settings → Transcript**, choose **Daily files (YYYY-MM-DD.txt)** and select the folder containing your dated transcripts. AAC Link opens today’s file and switches automatically at midnight using the Windows PC’s local date. If the next file doesn’t exist yet, the app waits for it without reusing yesterday’s transcript.

**Single file** remains available and stays selected for existing setups. This is a portable Windows x64 preview. Exit the older version from the tray before running the replacement executable.
